# CyberSpectra Skyrim Mod Assistant

A Vortex extension focused on making Nexus Mods collection installation less repetitive for free Nexus accounts while respecting Nexus Mods access controls.

The current project is in the design and implementation-planning stage. See `docs/superpowers/specs/2026-09-17-skyrim-mod-assistant-design.md` for the approved architecture.
